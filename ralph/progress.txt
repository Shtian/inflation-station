## Codebase Patterns
- For replaceable month-scoped AI outputs, model a single row per month with a unique `monthStart` and persisted lifecycle metadata (`status`, `generatedAt`, `errorMessage`, `reviewText`).
- Persist monthly-review system prompt in a singleton table row with a fixed key, and resolve blank/missing prompt text to a default prompt in the backend service layer.
- Keep monthly timeline aggregation in a route-independent service (`src/lib/monthly-review/overview.ts`) that computes spend from negative transactions, includes review-only months, and calculates MoM deltas only when the immediate prior calendar month exists.
