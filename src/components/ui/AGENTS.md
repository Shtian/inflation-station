# UI Primitives AGENTS

Load this when working in `src/components/ui`.

- Use canonical table primitives from `table.tsx` (`Table`, `TableHeader`, `TableBody`, `TableRow`, `TableHead`, `TableCell`) instead of ad-hoc markup.
- Use chart primitives from `chart.tsx` (`ChartContainer` and tooltip helpers) for overview visualizations.
- Prefer semantic design tokens (`bg-background`, `text-foreground`, `border-border`, etc.) over hardcoded palette classes.
